# Logo

Coloque aquí el archivo del logo con el nombre exacto `logo-fajitex.png`.

La barra de navegación lo carga desde `assets/logo-fajitex.png`. Mientras el archivo
no exista, la página muestra automáticamente la marca escrita "fajitex" como respaldo,
en minúsculas y sin serifa, con la j en morado.

Recomendación: PNG con fondo transparente, alto mínimo de 80 píxeles.
